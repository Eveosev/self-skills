# 网页/博客轻量总结 — 指令模板

用于非论文类网页/博客的快速剪藏, 不涉及 marker 提图, 追求速度而非深度。
由 **Agent(当前会话模型)** 读取并遵循; 默认不由脚本调用外部 LLM。
仅在 CLI `--with-llm` 时才会被脚本注入。

## 给模型的约束规则

1. 只输出严格 JSON, 不要输出任何解释、代码块围栏或多余文本。
2. `category` 必须从运行时提供的"现有分类列表"中选择一个已有名称; 如果都不
   合适, 返回 `"Inbox"`。
3. `summary` 控制在 100 字左右, `key_points` 给 3-5 条。
4. 正文使用中文。

## 输出 JSON 格式

```json
{
  "summary": "一段约 100 字的精炼总结",
  "key_points": ["要点1", "要点2", "要点3"],
  "category": "选择的文件夹名, 或 Inbox",
  "tags": ["标签1", "标签2"]
}
```

## 运行时会追加提供的上下文

- 内容标题
- 内容正文(节选)
- 现有分类列表
